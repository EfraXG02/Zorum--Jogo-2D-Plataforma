# 🎮 [Zorum]

Um jogo 2D desenvolvido na **Godot Engine** com scripts em **GDScript**.

👉 **[CLIQUE AQUI PARA JOGAR NO ITCH.IO](https://efraxg02.itch.io/zorum)** 👈

---

## 🕹️ Sobre o Jogo

-  Preso em uma montanha, precisa escapar!

- **Gênero:** Platformer / Metroidvania / Ação
- **Engine:** Godot Engine
- **Linguagem:** GDScript

---

## 🛠️ O que foi desenvolvido

- Lógica de movimentação e física do personagem.
- Sistema de colisão, inimigos e estados.
- Interface de usuário (HUD, menus e pontuação).
